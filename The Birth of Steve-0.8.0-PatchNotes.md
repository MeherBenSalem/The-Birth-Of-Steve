# The Birth of Steve v0.8.0

### New Features
* None

### Improvements
* **Archive floor themes redrawn.** Catalogue, Choir, Descent, Gallery, Labyrinth, Unwritten, Vault, and Wake floor, floor-side, and wall textures are refreshed.
* **Campaign item icons redrawn.** Archive Survey Map, Cantor Sigil, Chronicle Shard, Yesterglass Lens (intact and cracked), Curator Core, Memory Plate, and Recalled Hour use new item textures.

### Bug Fixes
* None

### Removals
* None

### Configuration
* None

### Compatibility
* Drop-in update from 0.7.1 for all shipped targets.
* Shared version **0.8.0** on every shipped target:
  * Fabric + Forge 1.20.1
  * Fabric + NeoForge 1.21.1
  * Fabric + NeoForge 26.1.2
  * Fabric + NeoForge 26.2
* Existing worlds keep Archive runs and site progress. No data format changes.

### Upgrade Notes
1. Replace the old `tbos-*-0.7.1.jar` with the matching `tbos-*-0.8.0.jar` for both your Minecraft version and your loader.
2. Restart the client or dedicated server.
3. Confirm the log lists **The Birth of Steve 0.8.0**.
4. Enter an Archive floor and check theme blocks and key items show the new art.
