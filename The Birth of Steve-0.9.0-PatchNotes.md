# The Birth of Steve 0.9.0 — Living Memories

**Released:** 2026-09-05

## Highlights

- **Living Memories** — draft a combat memory build during Archive expeditions.
- Clear rooms for three-choice offers; equip up to three actives and unlock
  passives that only apply inside the Fractured Archive.
- Six actives (Echo Lance, Recall, Parallax Step, Resonant Guard, Reconstruct,
  Memory Well) and twelve artifacts (prisms, conduits, bulwarks, and more).
- Open the Memory screen from the Archivist's Journal or the Memory keybind.
